# 로컬 ML 연구와 다음 세션 관찰

`make ml`은 최신 라벨을 동기화해 학습·평가하고 모델과 리포트를 저장한다.
자동 주문, 관심종목 변경, 운영 모델 교체는 하지 않는다.

## 실행

```bash
make ml
SKIP_SYNC=1 make ml  # 이미 동기화한 캐시로 재현
```

`local/ml/run.sh`는 EC2의 원장·history와 MySQL selection/forward_return을
가져온다. 일반 SSH 호스트 검증에 문제가 있으면 검증을 끄지 말고 Tailscale SSH로
인증한 세션에서 `remote_dump.py`와 선정 원장을 가져온 뒤 SKIP_SYNC로 실행한다.
2026-09-29 실행은 이 방식으로 같은 날 10,335개 라벨과 선정 원장을 동기화했다.

- `data/ml/train_labeled.json`: DB 원본 스냅샷. D1/D5 라벨 확인일 포함.
- `data/ml/train_comparison.json`: 날짜·시장·종목·13개 입력 특성이 같은 선정
  원장에서만 기존 규칙 점수를 복원한다. 모호하거나 불일치하면 비워 둔다.
- 시장별 30개 고유 선정일이 최소 실행 기준이다. 선정일에는 주말도 존재해
  독립 거래소 세션 수로 해석하면 안 된다. 임계 통과는 통계적 충분성 보장이 아니다.
- 산출물: `local/ml/out/YYYY-MM-DD/report.md`, `summary.json`, 모델 6개와 manifest.
- 실행 이력: `local/ml/registry.jsonl`. 동일 입력과 고정 seed로 다시 돌리면
  새로운 학습 자료가 생기거나 능력이 자동 누적되는 것은 아니다.

`PUSH=1`은 요약을 서버 inbox에 복사할 뿐 운영 모델로 승격하지 않는다.

## 검증 방식 (2026-09-29 수정)

- 뉴스·거래량·수급 등 기존 13개 특성으로 D1 방향·수익률, D5 방향을 예측한다.
- 초기 warmup 뒤 과거만 사용하는 expanding walk-forward. 경계에서 타깃 지평과
  embargo만큼 날짜를 제외하고, 라벨 확인일이 있으면 테스트 시작일보다 엄격히
  이전에 확인된 라벨만 학습한다. 각 fold의 실제 학습/평가 날짜를 기록한다.
- 파라미터는 기존 기본값 100 trees / depth 3 / learning rate 0.1로 고정한다.
  기본 실행의 탐색은 0회다. 평가 결과로 파라미터를 고르지 않는다.
- 베이스라인 비교는 당시 입력이 일치한 부분 표본에 한한다. 전방수익률 평균은
  수수료·슬리피지를 반영한 매매 성과가 아니다.
- 평가 방식이 다른 이전 기록과 수치 델타를 계산하지 않는다.
- 모델마다 feature 순서, 훈련 중앙값, 학습 기간·라벨 확인일, SHA256을 보존한다.
  저장된 분류기 자체는 미보정이다. 관찰 실행은 D1 회귀 모델만 사용한다.

## 현재 알려진 데이터 제한

원천 outcome은 기업행사·가격 조정 기준이 검증되지 않았다. US에는 +1,000%를
넘는 D1 라벨이 있고, 보고서 날짜와 기준가 날짜가 다른 행도 있다. 극단치를
잘라 성적을 좋게 만들지 않는다. 모델 manifest는 `promotion_allowed: false`와
`label_quality`를 명시한다. 이번 결과는 데이터 품질 진단·관찰용이며 매매 채택
근거가 아니다. 가격 기준과 정확한 지평을 검증하는 일이 다음 선행 과제다.

## 고정 모델 관찰 실행

`server/scripts/ml_shadow.py`는 명시적으로 설치한 자체 생성 모델만 읽는다.
모델과 manifest의 해시·특성 순서·중앙값·학습 종료/라벨 확인일을 검사한다.
프로세스 실행일의 선정만 점수화하고 기존 `ml_scorer`와 별도 `ml_shadow`
생산자로 판단을 남긴다. 모델과 전처리 전체가 버전에 반영된다.

```bash
.venv-ml-shadow/bin/python server/scripts/ml_shadow.py \
  --market KR --model-dir data/ml_models/2026-09-29
```

`data/ml_shadow/YYYY-MM-DD_MARKET.{json,md}`에 전체 예측·입력·대체된 값,
전체 ML 상위5개, 동일한 규칙 점수 보유 후보끼리의 상위5개 비교를 남긴다.
새 모델을 기존 주문·워치리스트에 연결하지 않는다. 실제 모델은 파일을 읽는 것만으로
코드가 실행될 수 있는 joblib 형식이므로 외부에서 받은 파일을 넣지 않는다.
