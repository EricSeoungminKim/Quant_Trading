# 시작점 — 이 Vault는 무엇인가

`quant_trading_kiwoom` 저장소의 **지식 그래프 + 운영 기억**이다. 두 개의 층으로 되어 있다.

| 층 | 위치 | 누가 쓰나 | git 추적 |
| --- | --- | --- | --- |
| **손으로 쓴 기억** | `docs/vault/*.md` (이 폴더 최상단) | 사람과 AI가 대화하며 갱신 | ✅ 추적 |
| **자동 생성 그래프** | `docs/vault/graph/` (노트 4,016개) | `/graphify`가 코드·문서에서 추출 | ❌ 미추적 (재생성 가능) |

## 손으로 쓴 노트 (여기서 시작)

- **[[착수보고서]] ← 새 세션이면 이것부터.** 이 프로젝트가 무엇을 만드는지,
  무엇이 끝났고 뭐가 남았는지, 왜 그렇게 하는지(원칙)를 한 파일에 담았다.
  **다른 Claude 계정·세션이 이 문서 하나만 읽고 이어서 일할 수 있게** 쓴 인수인계
  문서다. 작업이 끝나거나 추가될 때마다 갱신한다.
- [[시스템-작동방식]] — 하루가 어떻게 돌아가는가 (크론 → 엔진 → 텔레그램)
- [[기능-목록]] — 지금 쓸 수 있는 명령어·전략·안전장치 전부
- [[변경기록]] — 우리가 무엇을 왜 바꿨는지 (날짜순)

## AI에게: 이 저장소 질문에 답하는 순서

1. **그래프 먼저** — `graphify query "질문"`을 실행한다. 3,841개 노드 / 13,360개 엣지에
   코드·문서·운영 절차가 전부 들어 있다. 파일을 하나씩 열어 읽는 것보다 빠르고 정확하다.
2. **손으로 쓴 노트** — 위 4개 노트는 그래프가 모르는 것(왜 이렇게 정했는지, 사용자
   선호, 운영 중 겪은 사건)을 담는다. 그래프와 충돌하면 **이쪽이 최신**이다.
3. **그래도 모르면 코드** — `graphify explain "노드명"` 또는 실제 파일 읽기.

```bash
graphify query "손절 후 재진입은 어떻게 막히나"
```

```bash
graphify path "IntradayScanStrategy" "RiskManagerImpl"
```

## AI에게: 변경했으면 기록한다

코드를 고치거나 운영 설정을 바꿨으면 **같은 턴에** [[변경기록]] 맨 위에 한 항목을
추가한다. 형식은 그 노트 상단에 있다. 기록하지 않은 변경은 다음 세션에서 없는 것과 같다.

기능이 늘거나 동작 방식이 바뀌었으면 [[기능-목록]]과 [[시스템-작동방식]]도 같이 고친다.

## 그래프 재생성

코드가 많이 바뀌어 그래프가 낡았다고 느끼면:

```bash
/graphify . --update
```

바뀐 파일만 다시 추출한다. 그 후 vault 재생성:

```bash
graphify export obsidian --dir docs/vault/graph
```
