## 절대 하지 말 것

- **`MODE=live`를 임의로 켜지 않는다** — 사용자가 명시적으로 "실전으로 가자"고
  말할 때까지 paper 고정. 이건 사용자와의 약속이다.
- 시크릿 커밋 금지 (`.env.local`, `*.pem`). `git add -f`로 우회하지 않는다.
- 거래 핫패스(`quant.apps.cli paper`)에 LLM/네트워크 대기 추가 금지.
- 테스트를 약화시켜 통과시키지 않는다 (`skip`/`only`, assertion 삭제, mock으로 은폐).
- `quant/adapters/data/stub.py`(seed=42 합성 데이터)를 paper/live 경로에서 쓰지 않는다.

## 계좌 구조

| 용도 | 브로커 | 상태 |
| --- | --- | --- |
| 주문 집행 | Toss | 유일한 주문 경로 |
| 실시간 시세 | 키움 REST + 웹소켓 | 데이터 전용 (영원히) |
| 해외증권 | 키움 `KIWOOM_GLOBAL_*` | 키 슬롯만, 엔진 미배선 |

- Toss Open API는 **등록된 IP만** 허용한다 (그 외 403). 로컬 Mac에서는 조회가 막힌다.
- 키움은 지정단말기 IP 등록 필요. 모의(mockapi)와 실전(api)은 **토큰이 호환되지 않는다**
  — 토큰 캐시는 `base_url`을 키에 포함한다.
