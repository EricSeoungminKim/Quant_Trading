# 전략·지표 지도 — 무엇이 무엇을 보는가

"우리 시그널이 뭘 근거로 나오나"를 한 장으로. 코드를 열기 전에 여기서 방향을 잡는다.

## 활성 전략 7개

배분은 **시장별**이다(2026-08-12). donchian이 TQQQ/SQQQ 고정이라 KR 세션에
자본 40%가 놀던 문제를 없앤 것 — 이제 각 시장에 100%가 배치된다.

| 전략 | 축 | 진입 근거 | 검증 | 🇰🇷 KR | 🇺🇸 US |
| --- | --- | --- | --- | --- | --- |
| `donchian` | 돌파 | TQQQ/SQQQ 15분봉 채널 돌파 + 거래량 | **verified** | 0.00 | 0.30 |
| `orb_scan` | 돌파 | 개장 5분 범위 돌파(롱 온리) | burn_in | 0.20 | 0.20 |
| `intraday_scan` | 돌파 | 세션 신고가 + 거래량 2배 | burn_in | 0.20 | 0.20 |
| `news_momentum` | **뉴스 촉매** | EVENT 태그 종목을 개장 즉시 (아래 참고) | burn_in | 0.20 | 0.00 |
| `confluence` | **지표 합류** | 아래 5축 중 3축 이상 동의 | burn_in | 0.15 | 0.20 |
| `mean_reversion` | 평균회귀 | 일봉 z(20)<−2 + RSI(2)<10 과매도 반등 | burn_in | 0.15 | 0.00 |
| `cross_momentum` | 상대강도 | 주 1회 상대 모멘텀 상위 2종목 로테이션 | burn_in | 0.10 | 0.10 |
| | | | | **1.00** | **1.00** |

**0의 의미가 셋 다 다르다** — 이걸 혼동하면 "왜 이 전략은 배분이 없지?"에 잘못
답하게 된다:
- `donchian` KR 0.00 / `mean_reversion` US 0.00 — **구조적 사실**. 심볼이 고정돼
  있어 그 시장에서 신호 자체를 낼 수 없다. 배분을 줘도 죽은 자본이 된다.
- `news_momentum` US 0.00 — **데이터 소스 부재**. EVENT 태그는 한국 회사 리포트에서만
  나온다(US 자동 편입은 Toss 랭킹 → TREND 태그뿐). **US 뉴스 소스를 붙이면 열린다.**

이 배분은 **성과 기반이 아니다.** 종결 9건뿐이고 스코어보드가 "표본 부족 — 이
숫자로 자본 배분을 결정하지 마라"고 직접 경고한다. 구조적 사실만 반영했고,
**종결 30건 + 승률 유의** 이후 성과로 재배분한다.

시장별 합계가 각각 1.00을 넘으면 `validated_capital_fractions`가 그 시장만
비례 축소하고 ERROR를 남긴다(회귀 테스트가 실제 설정의 시장별 합을 검사한다).

## `news_momentum` — 뉴스를 어떻게 거래로 옮기나

```
08:40  브리핑(Claude, 리포팅 레이어) → EVENT 태그
       → 확신도 엔진(갭·거래량 스파이크·뉴스 신선도) + 키움 수급 → 통과분만 태그와 함께 저장
09:00  엔진(결정론적) → EVENT 태그 종목만 개장 즉시 진입
```

핫패스에 LLM이 없다(ADR-0002). 판단은 장 시작 전에 끝나고, 장중엔 그 결과를 읽기만 한다.

청산 사다리(고정 %): **−2% 손절 / +5% 절반 / +10% 전량 / 30분 타임아웃**.
진입은 개장 후 120초 창 안에서만, 종목당 세션 1회, 하루 최대 3종목.

**[미검증]이고 구조적 불리함이 있다**: 호재가 있으면 이미 갭업으로 시작하므로
우리가 사는 가격은 뉴스를 이미 반영한 가격이다. −2%는 KR 개장 직후 변동성에서
타이트해 승률이 낮을 것으로 예상된다.

## `confluence`의 5개 투표 축

단일 지표로 매매하지 않는다 — 문헌의 공통 결론이자 이 저장소 원칙이다.
(MACD 단독 크로스오버 승률은 대략 동전던지기, 볼린저 스퀴즈는 **방향 정보가 아예 없다**.)

1. **추세** — 종가 > SMA20 > SMA50 (정배열)
2. **모멘텀** — MACD 골든크로스가 최근 N봉 내 발생
3. **평균회귀 반등** — RSI가 30 아래→위 회복, 또는 %b가 0 아래→위 회복
4. **변동성 확장** — 직전 봉 스퀴즈 + 현재 봉이 볼린저 상단 종가 돌파
5. **박스 돌파** — `detect_box` 참 + 종가가 box_high 돌파 + 거래량 게이트

청산: ATR 손절 / 1.5R에서 30% 부분익절 후 잔여분 본전 스톱 / RSI 과매수 이탈 /
MACD 데드크로스 / EoD 강제청산 / 세션 롤 오버나이트 금지.

## 지표 계층 (`quant/trade/indicators/`)

순수 함수. 네트워크·config·브로커 임포트 없음(도메인과 같은 등급).

| 함수 | 파라미터(문헌 표준) | 비고 |
| --- | --- | --- |
| `rsi` | 14 | **Wilder 평활** — 단순평균 RSI와 값이 다르다 |
| `macd` | 12 / 26 / 9 | EMA 기반, `(line, signal, hist)` |
| `bollinger` | 20, 2σ | `+bandwidth`, `+percent_b` |
| `sma` / `ema` | — | |
| `squeeze` | 20, lookback 20 | 밴드폭이 최근 최저일 때 True |
| `detect_box` | lookback 20, tol 1.5% | 횡보 구간 + box_high/low |

**워밍업 구간은 NaN 그대로 둔다.** 0으로 채우면 호출부가 "값이 없다"와 "값이 0이다"를
구분할 수 없다 — 이 저장소가 반복해서 겪은 "실패를 빈 값으로 위장" 패턴이다.

## 파라미터를 고르지 않았다는 점

전부 **문헌 표준값**이다. 조합을 여러 개 시도해 최적값을 고르지 않았다 —
그게 다중검정 편향(in-sample 과최적화)의 시작이기 때문이다. `orb.py`의 도지 임계
0.50%가 "15개 이상 조합을 시도한 뒤 나온 값"이라 아직 채택 근거가 아닌 것과 같은 이유다.

웹에 떠도는 "RSI+MACD 승률 77%", "MACD+볼린저 78%" 류 수치는 **검증 불가능한 벤더
주장**이다. 규칙의 출처로만 참고했고 성과 주장으로 옮기지 않았다.

## 승격 경로 (burn_in → verified)

조건: 스코어보드 **종결 30건 이상** + 승률 신뢰구간이 50%를 위로 벗어남.
사람이 `evidence`를 채워 올린다 — 코드가 자동 승격하지 않는다(성적이 좋아 보이는
순간이 과최적화가 시작되는 순간이다).

**⚠️ 승격 시 반드시 배분 합계를 재확인한다.** verified가 되면 burn_in 캡(0.2)이
풀려 선언값이 그대로 살아나므로 **시장별 합이 1.00을 넘을 수 있다.** 가드가 그 시장만
비례 축소하지만 그건 의도한 배분이 아니다 — 승격과 재배분은 한 묶음으로 한다.

**승격 경로는 2026-08-12 새벽에 뚫렸다** — 멀티마켓 캘린더 + `--symbols` 오버라이드:

```bash
uv run python -m quant.apps.cli backtest --strategy confluence --days 90 --symbols "069500 229200" --source history
```

서버에 KR 1분봉 백필됨(069500/229200/122630, 2026-05-01~). 실측으로 confluence가
KR 실데이터 90일에서 12건 발화했다(승률 50%, +0.21% — 표본이 작아 성과 판단은 불가).
백테스트 리포트가 `strategy_errors`를 함께 출력하므로 **"0거래 + 에러 0"(조건
미충족)과 "0거래 + 에러 N"(침묵 실패)을 구분할 수 있다.**

**남은 한계**: 과거 시점 관심종목 스냅샷이 존재하지 않아 관심종목 전략의 "그날
유니버스"를 역사적으로 재현할 방법이 없다 — 코드 수정이 아니라 미해결 설계 문제다.
`--symbols`로 특정 종목을 지정해 돌리는 것은 되지만, "그날 실제로 무엇을 봤는가"의
재현은 아니다.
