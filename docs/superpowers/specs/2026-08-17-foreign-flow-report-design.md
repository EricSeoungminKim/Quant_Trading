# 외국인 수급 중심 리포트 개선 (서브프로젝트 I) — 설계 스펙

> 2026-08-17 사용자 지시. 원문 요지를 판단 규칙으로 보존한다.
> **적용 범위는 리포트다** — "리포트와 퀀트 전략은 따로 움직이기에, 현재는 리포트
> 쪽을 확실히 반영해서 종목을 선정하는 것" (전략 평면 무접촉; 미국장 종가배팅
> 전략화는 별도 결정 필요 — 백로그).

## 사용자가 정한 원칙 (판단 규칙)

1. **한국장 메인 로직은 외국인 매수세다.** "한국주식은 기관 매수세는 노이즈 —
   메인 리서치와 비리 없는 매수는 오로지 외국인 매수 추세". 기관은 리포트에
   **표시는 남기되** 로직 비중을 주지 않는다.
2. **국내 뉴스는 다 똑같은 말 = 노이즈** — 사건 단위 중복 제거를 확실히.
3. **DART 공시는 후발주자 리스크** (퍼블릭 공개 전 정보 유출 가능성) — 그래도
   중요하고 믿음직. 대처: 공시발 후보는 **박스를 좁게**(고점·저점 줄인 손절/익절)
   — 리포트에 안내 문구로 반영(전략 파라미터 변경 아님).
4. **자동매매 2원칙**: 승률이 아니라 손익비(잃을 땐 작게, 먹을 땐 크게) /
   감정 배제, 수치·데이터만.

## 외국인 수급 추종 규칙 (사용자 예시를 결정론 라벨로)

종목별 일별 외국인 순매수 시계열에서 (누적 순잔여 = 관찰 창 내 순매수 합):

- 유입 후 일부 이탈(예: +100억 → 익일 -50억): **잔여 자본이 남아 있다** —
  부분 익절/조정 노림 가능성. 라벨 `관망(잔여 있음)` — 하루 더 본다.
- 이탈이 연달아 이어짐: 지수·타 주체가 받쳐도 **하락 추세 가능성** —
  라벨 `이탈 추세(부분 매도/중립 고려)`.
- 이탈 후 재유입, 특히 이전 이탈분을 넘는 재유입: **매수 시그널** —
  라벨 `매수 시그널(재유입)`. 하루 유입·분할 유입 모두 인정.
- 이탈→재유입 반복(하루 단위 교차): `관망(하루 더)` — 다음날 추세로 스탠스 조정.
- 외국인 유입에 기관이 따라붙으면 강화 신호(참고 표기) — 단 기관 단독은 무시.
- 전 저점·현 고점 맥락: 개미 털기성 하락 구간 가능성을 명시(라벨이 아니라
  각주 — 가격 맥락 판단은 사람 몫으로 남긴다).

## 워크플로우 (한국장) — 리포트가 이 순서로 보이게

1. 섹터/종목별 외국인 수급 양 체크(탑다운): 업종 → 대장주 → 종목별 외국인 추세
2. 종목별 라벨 + 일별 근거(막대) + 진입 고려 표시
3. 관찰 명단은 코스피 종합 외국인 추세(당일 유입/이탈)로 스탠스 조정 참고

## 리포트 추가 요소 (회사 리포트 http://13.209.240.206:9999 벤치마킹)

- **시황 요약 섹션**: 한국장 뉴스 요약 + 미국발 뉴스의 한국 증시 영향 요약.
  결정론(클러스터 대표 사건 상위, KR발/미국발 분리)이 기본, 서술기(LLM)는
  있으면 한 문단 보강(없어도 완전한 섹션). 보험사류 잡음 섹션은 만들지 않는다.
- **클릭 → 네이버 이동**: KR 종목 어디서든 클릭하면
  `finance.naver.com/item/main.naver?code=XXXXXX` 새 탭. US 는 야후
  `finance.yahoo.com/quote/TICKER`. 그래프·상세는 유저가 네이버에서 직접 본다.
- **고정 브리핑 소스 추가**: 유튜브 `소라게아빠`(미·한 시장 신호등/차트 분석)
  BRIEF_CHANNELS 에 추가. 네이버 블로그 `침착해`(blog.naver.com/stock_blog,
  코스피 선물 트레이딩 관점) — 블로그 RSS(rss.blog.naver.com)로 최신글 칸.
- **DART 공시 활용**: 유형 태그(수주/FDA·임상/유상증자/실적 등) + 공시발 후보에
  "공시 후발 리스크 — 박스 좁게" 문구.

## 데이터 원천 (실측 확인됨)

- 종목별 일별 외국인/기관 순매수: `stock_detail`(finance.naver.com/item/frgn —
  이미 크롤 중, 현재 5일 합·연속일수로 축약 후 폐기) → **일별 행을 원장화**
  (`data/ledger/frgn_flow.jsonl`, date×symbol 멱등) + 상세 수집 대상을 후보
  상위 ~20 종목으로 확대(현재 6). 시장 종합 외국인은 features 에 이미 있음.
- 뉴스 사건: news_cluster(H-2). 공시: disclosures.jsonl(초기 2,000건 적재됨).

## 비목표
- 거래 엔진/전략 파라미터 변경(미국 종가배팅 전략화 포함 — 사용자 결정 대기),
- 가격 차트 재현(네이버 링크로 위임), LLM 필수화(모든 섹션은 무LLM 완전).
