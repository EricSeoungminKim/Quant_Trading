# 장 마감 포지션 리포트 (서브프로젝트 R) — 설계 스펙

> 2026-08-17 사용자 지시. 단타 실전 리듬: 08:00~10:30 첫 포지션 → 점심/마감 무렵
> 재서치 → **14:00~15:30 마감 포지션**. 아침 리포트(07:50)와 별도로, 그 사이에
> 낀 **당일 오후 전용 리포트**를 만들어 마감 포지션 진입을 돕는다.

## 발행 시각
- **13:40 KST 빌드 → 13:50 발행** (14:00 진입 준비 시간 확보). systemd 타이머
  매일(G 원칙) — 휴장일엔 조용한 내용이 그대로 정직하게 나간다.
- 산출물은 아침 리포트를 덮지 않는다: `out/YYYY/MM/DD/KR_close_report.html`
  (+ `KR_close_engine.json`). 텔레그램 발송 동일 패턴(요약+링크).

## 내용 (아침 리포트와의 차이가 존재 이유)
1. **장중 신규 호재**: 뉴스 창 = 아침 리포트 생성시각 이후 ~ 지금. 호재 마커
   (bullish_markers) 최우선 정렬, 악재 거부권 동일.
2. **당일 수급이 몰린 곳**: 시장 단위 장중 잠정 외국인/기관 순매수(코스피 —
   장중 제공되는 잠정치) + 종목 단위는 당일 랭킹(거래대금·상승률)과 전일까지의
   외국인 v2 추세 결합. **종목별 당일 외국인 확정치는 마감 후에만 존재** —
   잠정/확정을 위장하지 않고 "전일까지 추세 + 당일 시장 잠정"으로 정직하게 표기.
3. **마감 포지션 후보**: 단타 스코어러 v3 재계산 — 오후 컨텍스트(당일 장중
   등락·거래대금 랭킹이 트렌딩 입력, 장중 신규 호재가 뉴스 입력). top-8,
   요인 분해 동일. producer `intraday_scorer_v3_close` 로 원장 분리 —
   아침/오후 선정의 성적을 따로 채점(검증 하네스가 자동 축적).
4. 형식: 아침 리포트의 축약판(Exec Summary·업종 히트맵 등 무거운 섹션 생략,
   호재·수급·후보 중심 1페이지 성격).

- 종목별 장중 잠정 수급 크롤 신설 없음(잠정치 부재를 위장하지 않는다).
