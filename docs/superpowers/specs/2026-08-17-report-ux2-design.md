# 리포트 UX 2차 (서브프로젝트 J) — 설계 스펙

> 2026-08-17 사용자 스크린샷 피드백. **지도 원칙(사용자 원문): "너는 알아도,
> 유저는 봤을 때 이해가 안되면 그건 필요없는 정보가 돼."** 모든 수치 라벨은
> 단독으로 읽혀야 한다.

## 요구 6건

1. **뉴스 다양성 복원** — 퀀트 엔진으로 넘어가는 뉴스는 DART 공시·외국인
   추세가 우선이지만, **리포트는 네이버 증권처럼 여러 곳의 뉴스가 풍성하게**
   보여야 한다(이전 버전처럼). → "오늘의 뉴스 흐름" 섹션: 사건 단위 그룹
   전체(다이제스트 상위 8건 제한과 별개), 대표 제목 + 매체 배지 + `<details>`
   로 클러스터 전체. 정보 소실 금지.
2. **시황 다이제스트 = 경제지 큐레이션 + LLM 요약 허용** — 지금은 아무
   신문이나 들어간다. 경제/주식 전문지(한국경제·매일경제·서울경제·이데일리·
   머니투데이·아시아경제·파이낸셜뉴스·조선비즈·헤럴드경제·연합인포맥스 등
   상수 목록, 실측 조정 대상)만 다이제스트 후보로. **여기엔 LLM 사용 허용**
   (사용자 명시): narrator 경유 국내 1문단 + 미국발→한국 영향 1문단 요약,
   키 부재/실패 시 결정론 목록만(무LLM 완전성 유지).
3. **업종 관련 전반 히트맵 UI** — 업종별 시세·업종상위·**휴장 이월 후보**
   (지금 평면 나열이라 많으면 못 봄)를 서버사이드 CSS 히트맵 타일로:
   색 = 등락률(상승 적색/하락 청색 강도 5단계, KR 관례), 타일 안 이름+등락률,
   이월 후보는 **섹터별 그룹** 타일 + 이월일 배지. 범례 필수. JS 금지(기존
   원칙), 다크/라이트 양테마 대비 유지.
4. **기술적 지표도 클릭 → 네이버** — S&P 섹터(XLK 등)·기술 지표에 나오는
   종목/ETF 이름 클릭 시 네이버 증권 해외 페이지로(URL 형태는 실측 검증,
   막히면 야후 폴백).
5. **종목 카드 헤더 정리** — 10칸 히스토리 박스·"2일 연속"·"10일 중 4일·누적
   49건"은 직관적이지 않고 중요하지 않다 → 제거. 그 자리에 **전일 기준 가격
   변동 + 현재가**. 뉴스 맥락은 "뉴스 오늘 N건" 하나로 축약.
6. **수급 문구 정확화** — "전체 누적 외 +276만주 · 기 -679만주"의 '누적'은
   보유량처럼 읽혀 음수가 말이 안 된다는 지적 → 실체는 **기간 순매수 합**
   (매수-매도, 음수 = 팔자 우위). 라벨을 "원장 N일 순매수 합"으로, 각주에
   "순매수 = 매수-매도. 음수면 판 물량이 더 많았다는 뜻". "5일 중 2일치" 류도
   "원장에 기록된 날 수" 임을 문구로. 전 라벨 자기설명 점검 1회.

  뉴스 수집 소스 자체 변경(표시·큐레이션만).
