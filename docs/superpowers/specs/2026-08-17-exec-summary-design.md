# Executive Summary + 검증 백테스트 (서브프로젝트 L) — 설계 스펙

> 2026-08-17 사용자 지시(2차). 회사 리포트(13.209.240.206:9999)의 Executive
> Summary 급 통합 요약을 우리 근거(뉴스 빅데이터+수급)로 만들고, 리포트 추천의
> 실전 손익을 백테스트로 검증한다. 완료 후 **E2E 구멍 검증 패스** 필수.

## L-1. Executive Summary 통합 (지금 시황·뉴스 흐름이 따로 놀고 짤림)
- 리포트 최상단에 회사 리포트式 **통합 요약 블록**: 증시 흐름 문단 + 수급
  문단(외국인 중심) + 주요 사건 문단(국내/미국발) — **본문 스크랩 기반 AI 요약**.
- 헤더만이 아니라 `article_body`(이미 존재, 4000자 캡)로 상위 사건 기사 본문을
  긁어 LLM에 근거로 투입. LLM 산출엔 **근거 각주**(어떤 기사·수급 수치를 봤는지)
  를 붙인다 — 사용자: "근거들을 정확하게 모아서 LLM이 글을 생성, LLM의 근거도
  조금 들어가면 확신도 있게".
- 무LLM 폴백: 지금의 결정론 다이제스트가 그대로 그 자리에.
- 시황 다이제스트·뉴스 흐름은 이 블록 아래로 위계 정리(따로 놀지 않게).

## L-2. 뉴스 흐름 출처 품질
- 의미있는 출처 우선: 증권/경제 전문(한경·매경 증권, Yahoo Finance, Bloomberg
  — **이미 수집 중**, 표시 계층 문제). KR 뉴스 흐름도 증권 관련 피드/키워드
  우선으로 필터·정렬하고, Bloomberg/Yahoo에서 한국 증시 언급 기사를 KR 리포트에
  편입(제목·본문에 Korea/KOSPI/한국 매칭). 종합지 잡음은 접기로 강등.

## L-3. S&P 52주 신고/신저 — 검증 + 이름 병기
- 실측: MRK·SOLV·TECH 는 실제 헬스케어 종목(맞는 데이터)이나 **티커만 보여서**
  TECH 가 섹터명처럼 읽히는 혼란. → 종목명 병기(티커+회사명), 클릭→네이버(기존
  검색 랜딩). 데이터 자체는 스팟체크(야후 52주 고가 대조 3~5종목)로 검증하고
  기준일을 명시(회사 리포트와 날짜 차이가 "다른 데이터"로 오해되지 않게).

## L-4. 히트맵 색상 — 상승=초록
- 사용자: 빨간색 잘 안 보임, 초록 사용(회사 리포트 관례). `--up` 히트맵 팔레트를
  초록 계열로 반전(u1~5=초록 강도, d1~5=연빨강/분홍), 등락 텍스트 색은 기존 유지
  여부 사용자 관례 확인 없이 히트맵만 우선 적용.

## L-5. LLM 전략 (하네스 현황 + Claude CLI 실험)
- 현황 보고: OpenRouter 무료(nemotron)가 지금 반영되는 지점(시황 AI 요약,
  close-report 서술, deepdive 관계 후보) 정리.
- 실험: **EC2 의 Claude Code CLI** 로 같은 입력(사건+본문+수급 근거)의 요약본을
  생성해 무료 LLM 산출과 나란히 비교(품질·근거 충실도) → 결과가 확실히 좋으면
  사용자에게 보고(유료 OpenRouter 키 도입 판단은 사용자).
