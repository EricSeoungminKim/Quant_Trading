## 구성요소

### E-1. 전 종목 기준가

`report_cli build` 의 시세 대상을 `rank(cont, 10)` 에서 **engine JSON 에 실리는
심볼 전부**로 확대한다. yfinance 는 배치라 호출 횟수는 그대로 1회. 매핑·조회
실패는 조용히 탈락시키지 않고 **개수를 로그로 남긴다**(기존 `_log_overlap`
스타일). 기대: 채점 교집합 하루 5 → 50+.

### E-2. 결정론 베이스라인 점수 (`baseline_score100`)

- `fetch_symbol_quotes` 가 종가만 주던 것을 **같은 배치에서 OHLCV 를 추가 키로**
  반환하게 확장한다(기존 키·소비자 무변경 — additive).
- 그 OHLCV 로 `watch_scorer._trend_score`(순수 함수, 이미 검증된 배점)를 전
  종목에 돌려 `baseline_score100` 을 payload 심볼에 싣는다(있을 때만 키 생성).
  새 신호를 발명하지 않는다 — 검증된 채점기의 적용 범위 확장이다.
  미완성 당일 봉 제거 방어(`score_symbol` 이 하던 것)를 여기서도 한다.
- `selection_judgment` 의 점수 출처를 `baseline_score100` 우선(없으면 기존
  `trending_score100`)으로 바꾸고 **producer_version 을 "2"** 로 올린다 —
  산식이 바뀌면 버전이 바뀌어야 v1 표본과 섞이지 않는다(002_judgment.sql 주석).

### E-3. 장마감 결과 텔레그램 + 전략 피드백

새 CLI 서브커맨드(예: `cli close-report`)가 **결정론 요약**을 출력:
- 오늘 만기 지평의 forward_return 상위/하위 (표본 수 병기)
- 전략별 원장 성적(스코어보드 요약 — "판단 불가"는 그대로 정직하게)
- 리더보드 `Verdict.reason` 한 줄 (당분간 insufficient_sample 이 정답)
- LLM 서술은 `narrate` 포트로 **선택적으로만** 얹는다 — 서술기가 죽어도 발송된다

발송은 `session_pnl.sh` 패턴 그대로(새 6줄 래퍼 + `.env.local` 의 스케줄 푸시
토큰). 크론 `20 16 * * 1-5` — `outcomes`(16:00)가 채운 값을 읽어야 하므로 이후.

### E-4. 20거래일 축적

코드가 아니라 시간이 하는 일. E-1·E-2 배포일부터 카운트.
