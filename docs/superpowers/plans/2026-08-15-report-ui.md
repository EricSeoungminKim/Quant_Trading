# 리포트 고도화 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자 요구 5건(뉴스 전량·수혜주 트리·테마별 시세·수급 기간 뷰·저장 축소)을 기존 jinja2 리포트에 구현한다.

**Architecture:** 프레임워크 도입 없음 — 상호작용은 `<details>`/CSS, 차트는 기존 서버사이드 SVG. A 가 만든 `relations`·`sector_map` 아티팩트의 첫 HTML 소비자다. 수급 기간 뷰는 외부에서 긁지 않고 **매일 스냅샷을 원장에 축적**한다.

**Tech Stack:** jinja2(autoescape 켜짐), regex 파싱(네이버), pandas 불필요, pytest.

**스펙:** `docs/superpowers/specs/2026-08-15-report-ui-design.md` — 먼저 읽을 것.

## Global Constraints

- **프레임워크·빌드 도입 금지.** Next.js/Vercel/클라이언트 JS 라이브러리 금지(스펙 §핵심결정 1). `<details>`/CSS 로 안 되는 게 나오면 구현하지 말고 보고하라.
- **`|safe` 금지.** `relations[].reason` 은 LLM 출력이다. jinja2 autoescape 를 그대로 두고, 렌더 결과에 실행 가능한 태그가 없음을 테스트로 고정한다.
- **없는 데이터를 0 으로 그리지 않는다.** 등락률 미확인은 "미확인", 축적 부족은 "N일치"로 표기. 빈 섹션은 아예 그리지 않는다(빈 트리 금지).
- **기존 소비자 무변경.** `fetch_sector_map` 계약 불변(함수 추가로 확장), `machine_payload` 기존 키 불변, 리포트 발행 시각·크론 무변경.
- **trade 평면 무접촉.** `tests/test_architecture.py` 통과, `KNOWN_DEBT` 추가 금지.
- 테스트 약화 금지. 커밋 메시지 한국어 "왜". 완료 주장 전 `uv run pytest -q` 전체.
