# 한국장 장전 진입 환경 브리핑

## 운영 목적

자동 리포트가 주 제품이다. 환경 점수는 미검증 고정 규칙을 매일 관찰하는 도구이며 상승 확률이나 수익 보장이 아니다. 관찰 비중 구간은 실제 계좌 주문·자본 설정에 쓰이지 않는다.

## 경로와 일정 (KST)

- 기존 `market-report-kr.timer` 07:30 기동 → 07:35 수집/빌드 → 목표 08:00 발행.
- `quant.apps.report_cli._emit` → `quant.apps.entry_environment.build_view` → 순수 `quant.analyze.entry_environment`.
- HTML과 engine.json, 기존 briefs Telegram 알림이 동일 점수를 사용한다.
- `entry-environment-feedback.timer`: 매일 16:40 결과 평가, 07:10 결측 재조회. 거래일을 추측해 이웃 봉으로 대체하지 않으며, 실제 장전 예측이 있는 날짜의 지수 일봉만 조회한다.
- 이 Codex 작업의 별도 아침 브리핑은 08:15. 앱 실행 환경 가용성이 필요하고, 서버의 HTML/Telegram 발행과는 독립이다.

## 점수와 근거

v1 고정 가중치: S&P500 20, NASDAQ 15, VIX 25, USD/KRW 15, WTI 변동 충격 10, 구리 5, 금 5, 날짜 확인된 CNN 심리 5. 요인별 선형 변환/상하한은 소스와 HTML 근거 표에 공개한다. 핵심 미국 지수/VIX가 없거나 출처 충돌이면 보류. 자료 충족 비중 60 미만도 보류. 일부 결측일에는 가용 가중치로 재정규화하므로 coverage를 함께 비교한다.

60 이상 up/40 이하 down/사이 flat, ±0.2%는 실제 결과의 보합 구간이다. 모두 사전 고정 초기값이며 훈련 성능 주장이 아니다. 높은 VIX·유가/환율 충격은 관찰 노출 구간을 제한한다. BTC 전일 UTC 봉은 KR08:00에 미완성일 수 있어 잠정값/점수 제외를 표시한다.

연준은 FRED `DFEDTARL`/`DFEDTARU` 목표 범위와 마지막 관측 변경 bp를 별도로 표시한다. 실효금리나 선물의 인상 확률과 혼용하지 않는다. Fed·업종·뉴스·텔레그램은 맥락 및 확인 과제다. 언급 빈도를 확인된 악재/호재 강도로 바꾸지 않으며, 검증 전 점수에 임의 가산하지 않는다. 주도 업종은 같은 날짜 최소 8개 US 섹터 중 양수 비율이 50% 이상일 때만 제시한다.

텔레그램은 기존 지정 채널 원장 72시간 창을 사용한다. 시간 불명/미래/빈 본문과 동일 ID·본문 중복을 제외한다. 사전 정의한 거시·섹터 키워드 사전, 채널 수·원문 링크·본문 SHA를 기록한다. 웹 프리뷰로 읽지 못한 채널은 결측이며 별도 비공개 방 접근을 시도하지 않는다.

## 예측과 평가 원장

- `data/entry_environment/forecasts/YYYY-MM-DD.json`: 실제 당일09:00 이전 최초 기록만 생성, 원자적 hard-link로 덮어쓰기 방지. 생성시각·동결시각·버전·해시·입력과 요인을 보존한다. 기존 예측이 있으면 재발행도 그것을 사용한다.
- `data/entry_environment/outcomes/YYYY-MM-DD.json`: 네이버 지수 차트(실측 원본 XML), 실패 시 Yahoo의 정확한 해당 날짜 KOSPI/KOSDAQ OHLC를 15:40 이후 검증. 양수/유한 가격·OHLC 관계 검사. 결측 지수는 다음 배치에서 재시도하고 먼저 확정한 지수는 유지한다.
- 타깃: 당일 시가 대비 종가 수익률 및 저가/시가 하락폭. 전일 종가 기준 기존 정확도와 별개다. 방향 오차는 down/flat/up 순서 거리 0~2이며 백분율 예측 오차가 아니다.
- 다음 리포트: 직전 예측 날짜 평가·미수집 표시, 방향 불일치 가설, 다음 아침까지 요인 변화, 누적 표본·Wilson구간·순위IC·항상 상승/보합 기준선. 원인 추정은 인과 증명이 아니며 전날 오차에 맞춰 가중치를 자동 조정하지 않는다.

## 점검·복구

```
.venv/bin/python -m quant.apps.entry_environment --root .
systemctl status entry-environment-feedback.timer
journalctl -u entry-environment-feedback.service -n 30
```

시스템 시간은 KST/aware이어야 한다. 과거 스냅샷 미리보기는 최초 예측 원장에 넣지 않는다. 손상된 JSONL 입력 행은 제외 수를 리포트 위험 항목에 표시한다. 예측 원장 자체가 손상되면 복원하며 새 점수로 덮어서 정합성을 가장하지 않는다.
