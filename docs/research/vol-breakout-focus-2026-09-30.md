# KR 변동성돌파 촉매형 집중 관찰 — 연구 기준

2026-09-30. 운영 기준은 `vol_breakout_cat`, KR, paper이며 `k=0.5`,
`min_stop_bp=40`, `eod_exit_min=5`를 고정한다. 파라미터 탐색 결과를 자동
승격하지 않는다. 이 문서는 새 연구의 실행 조건이며 과거 결과를 OOS로 바꾸지 않는다.

## 재현 가능한 원장 진단

```bash
uv run python -m quant.research.vol_breakout_review \
  --ledger /path/to/trades.jsonl --since 2026-09-07 --out /tmp/vol-breakout-review.json
```

날짜는 KST 자정으로 해석한다. 전체 원장을 기존 `ledger.round_trips`로 먼저
짝지은 뒤 진입 시각으로 필터한다. 원본은 읽기 전용이며 설정·주문을 바꾸지 않는다.
종결 왕복의 수수료 차감 순손익, PF, 승률, 평균 bp, 최대 거래/일/종목 제외,
종목별·일별 집중도와 추가 편도 슬리피지 5·10bp를 JSON으로 낸다.
추가 비용은 `2 × 진입 명목 × 편도 bp / 10,000` 근사다. 기존 수수료에
더하는 스트레스이며 정확한 매도 명목·미체결·시장충격 모형은 아니다.

계좌 규모가 달라지면 결과를 단순 비례 확대하지 않는다.

## 데이터 가용성 실측

EC2 `data/history`의 KR 분봉은 `심볼/연도/월.parquet`이라는 기존 포맷이다.
`심볼/1m/연도` 경로가 없다고 분봉이 없다고 판정하면 안 된다. 2026-09-30 조회:

- KR 숫자 심볼 165개, 분봉 월 파일 250개. 9월 133개, 8월 108개,
  5·6·7월 각 3개. 이는 파일 수이며 월 전체 세션이 완전하다는 뜻이 아니다.
- 000500은 19,322행, 042700은 17,705행, 000660은 20,821행.
  표본 파일들에 중복 인덱스는 없었지만 세션별 누락은 별도 조사해야 한다.
- 장전·장후 행도 있으므로 KRX 세션 달력과 봉 완료 시각으로 제한해야 한다.
- `selections.jsonl`은 13,930행이지만 확인한 계약에 날짜만 있고 프로그램의
  최초 인지·편입 시각이 없다. 이를 장전 촉매 유니버스의 시점 증거로 대체하지 않는다.
- KR 스냅샷 JSON 74개 존재. 개별 스냅샷 시각과 후보 편입 이벤트를 연결해야
  전체 후보 경로의 재현 가능 여부를 판정할 수 있다.

## 최소 연구 경로

1. **기준선 재현부터:** 실제 전략 코드와 고정 파라미터, 계좌·위험 예산,
   KR 세금·수수료, 세션 달력, 확정 봉 이후 체결 시점을 명시하고 동결한다.
   `quant/backtest/engine.py`는 공통 `run_cycle`을 재생하지만 정적 심볼 인자를
   오늘의 촉매 명단으로 채우면 과거 촉매형 검증이 되지 않는다.
2. **유니버스 증거:** 후보 최초 인지/편입/제외 시각, 태그와 이유, 설정·코드
   지문, 원천 분봉의 해시·시각 의미를 보존한다. 그 시각 이전에는 후보로
   사용하지 않는다. 필요한 이력이 없으면 가격 규칙만의 회고 진단으로 명명한다.
3. **체결 검증:** 기준선 replay와 원장의 진입·청산 날짜/이유를 대조한다.
   결측·VI·상하한가·거래정지를 제외하여 좋은 날만 남기지 않고 제한과 미체결을
   보고한다. EOD 5분 청산 시점의 데이터가 없으면 완전 재현으로 취급하지 않는다.
4. **작은 사전등록 탐색:** 다음 실행 전에 최대 7개 조합을 고정할 수 있다.
   기준선 1개와, 다른 두 값은 고정한 채 `k∈{0.4,0.6}`,
   `min_stop_bp∈{30,50}`, `eod_exit_min∈{3,10}`의 단일 변화 6개다.
   아직 실행하거나 채택한 조합은 없다. 설정 파일의 운영 값을 수정하지 않는다.
5. **시간순 검증:** 기존 `quant/research/walkforward.py`와
   `quant/backtest/purged_cv.py`를 재사용한다. 충분한 일자·후보 이력이 생긴 뒤
   학습 60거래일 / 시험 20거래일 / 최소 1거래일 embargo를 실행 전에 고정하고,
   시험 구간을 겹치지 않게 한다. 현재 짧은 촉매 표본으로는 이 설계를 채울 수 없다.
   이미 본 8~9월은 새 홀드아웃이 아니다. 표본 조건을 맞추려고 기간을 임의 축소하지 않는다.
6. **향후 관찰:** 오늘부터 모은 새 구간을 변경하지 않은 기준선으로 관찰한다.
   같은 후보·위험 예산에서 변형을 비교하고 전체 탐색 수, 비용 1배·2배,
   추가 슬리피지·체결 지연, 최악일/낙폭, 거래·종목 집중도, 오류·미청산을 보고한다.
   여러 조합을 보고 선택한 결과에는 선택 편향을 명시하고 독립된 다음 구간이 필요하다.

기존 `mtf_comparison.py`는 고정 5종목의 가격 유니버스와 15:10 공통 청산
정책을 사용한다. 이는 촉매 태그와 EOD 5분 규칙을 지킨 기준선의 대체재가 아니다.
기존 `optimize`에는 변동성돌파 기본 파라미터 공간도 없으므로 별도의 연구용
매니페스트가 필요하다. 누수 없는 재현이 확인되기 전 대규모 최적화를 시작하지 않는다.

### 무거래 진단 정정

당일 엔진 로그의 `당일 세션 시가 확인 불가` 반복4126회 이상을 데이터 장애
횟수로 해석하면 안 된다. 개장 직후 첫5분봉 미완성 때 기록한 `last_reject`가
정상적인 `price < trigger` 대기에서도 남아 shell이 매 사이클 다시 집계했다.
정상 대기 분기에서 오래된 사유를 제거하고, 결손 지속·새 결손 원인·돌파 신호는 유지한다.

EC2에 현재 저장된 Toss 분봉/일봉으로 사후 재현하면09:01에는 시가가 없고,
09:06·10:01·14:01·15:01에는 시가218,000원이 확인된다. 전일 고저233,000/205,000원과
k0.5의 돌파 기준은232,000원이다. 저장 분봉 고가231,000원, 관측 틱 최고230,500원은
이 문턱보다 낮다. 당시 엔진 메모리 전체를 보존한 증거는 아니므로 이 결과는
저장 자료의 사후 재현으로 명명한다. 매매 조건을 낮춰 체결을 만들지 않는다.
